2. База по семантике JavaScript

2.1. Что такое Date

Date — это встроенный объект JavaScript для работы с датой и временем. Когда ты пишешь new Date(), ты создаёшь объект даты. Внутри него хранится полный момент времени: год, месяц, день, часы, минуты, секунды и миллисекунды. 

const now = new Date();
console.log(now);

Это не «просто строка» и не «просто число». Это объект, у которого есть методы:

getTime() getMonth() getDate() getFullYear() getHours() getMinutes()

2.2. Что такое new

new — это оператор, который создаёт новый объект через конструктор. В случае new Date() он создаёт новый объект даты. 

const a = new Date();   // объект Date
const b = Date();       // строка с датой, а не объект Date
Важно: без new ты не получаешь тот же самый тип значения. Поэтому для работы с методами даты нужен именно new Date().

2.3. Конструктор — простыми словами

Конструктор — это штука, которая создаёт объект. В твоём случае: 

const d = new Date();

означает: «создай новый объект, внутри которого лежит текущая дата и время».

2.4. Что такое метод

Метод — это функция, которая принадлежит объекту. Например: 

const d = new Date();

d.getTime();
d.getMonth();
d.getFullYear();

Здесь getTime, getMonth, getFullYear — методы объекта даты d.

2.5. Что делает getTime()

getTime() возвращает не «только время суток», а количество миллисекунд с 1 января 1970 года до момента, который хранится в объекте даты. 

const d = new Date();
const timestamp = d.getTime();

console.log(timestamp);

Получится большое число вроде: 

1776619512000

Это удобно, потому что с числами можно делать арифметику: прибавлять сутки, неделю, час и потом обратно превращать в дату.

2.6. Что делает getMonth()

getMonth() возвращает индекс месяца от 0 до 11:

Индекс Месяц
0январь
1февраль
2март
3апрель
4май
5июнь
6июль
7август
8сентябрь
9октябрь
10ноябрь
11декабрь

2.7. Что делает getDate()

getDate() возвращает номер дня месяца: 1, 2, 3, ..., 31. 

const d = new Date();
console.log(d.getDate());

Это не timestamp и не миллисекунды. Поэтому для сдвига времени через арифметику getDate() не подходит.

2.8. Скобки и что они означают

  • () — вызов функции или метода, либо группировка выражения.
  • [] — доступ к элементу массива по индексу.
  • {} — блок кода или объект.
monthA[p.getMonth()]

Здесь:

  • p.getMonth() — вызываем метод и получаем число, например 3.
  • monthA[3] — берём 4-й элемент массива, то есть "апрель".

2.9. Что такое split()

split() — метод строки, который разбивает строку на массив по разделителю. 

const months = "январь,февраль,март".split(",");
console.log(months); // ["январь", "февраль", "март"]

2.10. Что такое textContent

textContent — свойство DOM-элемента, которое задаёт или читает его текстовое содержимое. 

document.getElementById("date").textContent = "апрель и май";

То есть ты находишь элемент на странице и подставляешь в него текст.

3. Разбор исходного кода построчно

d = new Date();
p = new Date(d.getTime() + 86400000);
let b = p.getMonth() + 1 > 11 ? 0 : p.getMonth() + 1;
monthA = "январь,февраль,март,апрель,май,июнь,июль,август,сентябрь,октябрь,ноябрь,декабрь".split(",");
document.write(
  monthA[p.getMonth()] + " " + "и " + monthA[b]
);

Строка 1

d = new Date();

Создаётся объект даты с текущим моментом времени.

Минус исходника: переменная создаётся без let/const, значит она утекает в глобальную область видимости.

Строка 2

p = new Date(d.getTime() + 86400000);

Берётся текущая дата d, превращается в число миллисекунд через getTime(), к нему прибавляются сутки (86400000), и затем это число снова превращается в объект даты.

Итого: p — это дата на 1 день позже, чем d.

Строка 3

let b = p.getMonth() + 1 > 11 ? 0 : p.getMonth() + 1;

Это тернарный оператор. Он вычисляет индекс следующего месяца.

  • Если p.getMonth() + 1 больше 11, значит вышли за декабрь.
  • Тогда возвращается 0, то есть январь.
  • Иначе берётся просто следующий индекс: текущий + 1.

Строка 4

monthA = "январь,февраль,март,...".split(",");

Строка месяцев превращается в массив строк.

Строка 5

document.write(
  monthA[p.getMonth()] + " " + "и " + monthA[b]
);

Берётся месяц по индексу p.getMonth() и следующий месяц по индексу b, затем они склеиваются в строку.

4. Зачем автор сдвигал дату на 1 день и почему это мутно

Вот это был твой главный логический затык, и он абсолютно понятный.

В нормальной задаче «показать текущий и следующий месяц» сдвиг даты на день вообще не нужен. Достаточно взять текущий месяц и вычислить следующий индекс.

Но автор исходника, вероятно, думал так:

  1. Если взять дату на следующий день, то на границе месяца она уже может оказаться в новом месяце.
  2. Значит можно отталкиваться не от сегодняшней даты, а от «почти следующего периода».
Но проблема: эта идея здесь избыточна. Она делает код более мутным и не даёт очевидной пользы для такой простой задачи.

Как ты правильно почувствовал проблему

Ты задал очень точный вопрос: «Если мы потом всё равно работаем только с месяцами, зачем вообще был нужен сдвиг на день?»

И это был правильный вопрос. Потому что:

  • если следующий день всё ещё в том же месяце — пользы нет,
  • если следующий день уже в новом месяце — это меняет логику, но делает её менее прозрачной,
  • для задачи про «текущий и следующий месяц» проще и честнее вообще не играться с днями.

Нормальная логика без этого костыля

const d = new Date();
const currentMonthIndex = d.getMonth();
const nextMonthIndex = currentMonthIndex === 11 ? 0 : currentMonthIndex + 1;

5. Почему split(",") работает, а split(", ") дал undefined

Вот твоя строка:

const monthA =
  "январь,февраль,март,апрель,май,июнь,июль,август,сентябрь,октябрь,ноябрь,декабрь"
  .split(", ");

Здесь ты сказал: «разбить строку по разделителю запятая + пробел». Но в исходной строке после запятой пробела нет.

Фактически строка такая:

"январь,февраль,март"

А ты ищешь такой разделитель:

", "

Его там нет, значит строка не делится:

const months = "январь,февраль,март".split(", ");
console.log(months);      // ["январь,февраль,март"]
console.log(months.length); // 1

Поэтому когда ты потом обращаешься к months[3] или months[7], получаешь undefined.

Правильный вариант

const months = "январь,февраль,март".split(",");
console.log(months); // ["январь", "февраль", "март"]

Запятая в конце split(",",)

Вот такая запись: 

.split(",",)

технически допустима, потому что это просто лишняя завершающая запятая в списке аргументов. Она здесь ничего не даёт и никак не улучшает код. Для обучения лучше писать без неё: 

.split(",")

6. Шпаргалка по времени и миллисекундам

Единица Сколько содержит В миллисекундах Готовое число
1 секунда 1000 миллисекунд 1 * 1000 1000
1 минута 60 секунд 60 * 1000 60000
1 час 60 минут 60 * 60 * 1000 3600000
1 день 24 часа 24 * 60 * 60 * 1000 86400000
2 дня 2 × 24 часа 2 * 24 * 60 * 60 * 1000 172800000
1 неделя 7 дней 7 * 24 * 60 * 60 * 1000 604800000

Как это раскладывать в голове

1 час = 60 минут
1 минута = 60 секунд
1 секунда = 1000 миллисекунд

1 час = 60 * 60 * 1000 = 3600000 мс
1 день = 24 * 60 * 60 * 1000 = 86400000 мс

Почему в исходнике было умножение на 1

86400 * 1000 * 1

Умножение на 1 здесь ничего не меняет. Иногда так пишут по инерции, как будто оставляют место для числа дней: 

oneDayInMs * 1
oneDayInMs * 2
oneDayInMs * 3

Но конкретно в исходнике это просто лишний шум.

Готовая шпаргалка для смещений

const SECOND = 1000;
const MINUTE = 60 * SECOND;
const HOUR = 60 * MINUTE;
const DAY = 24 * HOUR;
const WEEK = 7 * DAY;

Примеры:

const tomorrow = new Date(Date.now() + DAY);
const afterTwoDays = new Date(Date.now() + DAY * 2);
const nextWeek = new Date(Date.now() + WEEK);

7. Как отлаживать такой код через console.log

Тебе важно не просто писать код, а уметь видеть, где именно он ломается. Вот базовый шаблон отладки: 

const d = new Date();
console.log("d:", d);

const timestamp = d.getTime();
console.log("timestamp:", timestamp);

const DAY = 24 * 60 * 60 * 1000;
console.log("DAY:", DAY);

const p = new Date(timestamp + DAY);
console.log("p:", p);

const currentMonthIndex = d.getMonth();
console.log("currentMonthIndex:", currentMonthIndex);

const nextMonthIndex = currentMonthIndex === 11 ? 0 : currentMonthIndex + 1;
console.log("nextMonthIndex:", nextMonthIndex);

const monthA = "январь,февраль,март,апрель,май,июнь,июль,август,сентябрь,октябрь,ноябрь,декабрь".split(",");
console.log("monthA:", monthA);
console.log("monthA.length:", monthA.length);

console.log("currentMonthName:", monthA[currentMonthIndex]);
console.log("nextMonthName:", monthA[nextMonthIndex]);

Как проверять по шагам

  1. Сначала проверить, что дата вообще создаётся.
  2. Потом проверить, что getTime() дал число.
  3. Потом проверить, что смещение по миллисекундам дало новую дату.
  4. Потом проверить индекс текущего месяца.
  5. Потом проверить индекс следующего месяца.
  6. Потом проверить сам массив месяцев и его длину.
  7. И только потом уже склеивать итоговую строку.

Полезный приём: сначала собрать строку в переменную

const result = monthA[currentMonthIndex] + " и " + monthA[nextMonthIndex];
console.log("result:", result);

document.getElementById("date").textContent = result;
Почему это удобно: если строка уже готова в переменной, ты можешь проверить её в консоли ещё до вставки в DOM.

8. Почему document.write лучше не использовать

document.write() — старый способ писать текст прямо в поток документа. Для учебных маленьких примеров он ещё встречается, но в нормальном современном коде его стараются не использовать.

Почему он плох

  • плохо сочетается с современным управлением DOM,
  • может перезаписать документ, если вызвать в неподходящий момент,
  • хуже читается и хуже масштабируется.

Что вместо него

<span id="date"></span>
document.getElementById("date").textContent = "апрель и май";

То есть мы не «пишем в документ где попало», а находим конкретный элемент и подставляем в него текст.

9. Почему в современном варианте лучше const

Твой важный вопрос

«Если дата же как будто меняется, почему можно поставить const?»

Ответ

const запрещает переприсваивать переменную, а не «замораживает время». 

const d = new Date();

Это значит: переменная d всегда будет ссылаться на тот объект, который был создан в этой строке. Но сам объект даты внутри может содержать своё значение.

Что запрещено

const d = new Date();
d = new Date(); // ошибка

Почему это ок для нашего случая

Мы один раз создаём дату и потом читаем из неё данные. Нам не нужно переприсваивать переменную d. Значит, const подходит идеально.

Когда нужен let

Когда ты реально собираешься потом присвоить переменной новое значение. 

let monthIndex = 0;
monthIndex = monthIndex + 1;

Этот вариант не про месяцы, а про правильную запись смещения даты.

Вариант 5. Через функцию

function getMonthPairText() {
  const months = [
    "январь",
    "февраль",
    "март",
    "апрель",
    "май",
    "июнь",
    "июль",
    "август",
    "сентябрь",
    "октябрь",
    "ноябрь",
    "декабрь",
  ];

  const currentDate = new Date();
  const currentMonthIndex = currentDate.getMonth();
  const nextMonthIndex = (currentMonthIndex + 1) % 12;

  return months[currentMonthIndex] + " и " + months[nextMonthIndex];
}

document.getElementById("date").textContent = getMonthPairText();

Это полезно, когда хочешь отделить логику вычисления от вывода в HTML.

11. Твои реальные ошибки и как их быстро узнавать

Ошибка 1. В консоли появлялся undefined

В браузерной консоли это часто просто результат последнего выражения. Например: 

console.log(new Date());

console.log() сам по себе ничего не возвращает, поэтому консоль может показать: 

undefined

Но это не значит, что дата не вывелась. Это значит: лог вывелся отдельно, а возвращаемое значение вызова — undefined.

Как увидеть именно дату как результат выражения

new Date()

Тогда консоль покажет сам объект даты как результат последнего выражения.

Ошибка 2. Identifier has already been declared

Это происходило в DevTools, когда одна и та же переменная с const объявлялась повторно. 

const dat = new Date();
const dat = new Date(); // ошибка

Решения:

  • обновить страницу,
  • использовать другое имя переменной,
  • или выполнять код не по кускам в консоли, а в файле.

Ошибка 3. Перепутать getDate() и getTime()

  • getDate() — номер дня месяца.
  • getTime() — timestamp в миллисекундах.

Для арифметики со временем нужен именно getTime().

Ошибка 4. split(", ") вместо split(",")

Из-за этого массив не разбивался, и потом всё превращалось в undefined.

Ошибка 5. Английское and в русском тексте

Технически код работает, но по смыслу лучше: 

" и "

а не: 

" and "

12. Финальное ТЗ для самостоятельной практики

Ниже задание уже не на переписывание исходника, а на самостоятельную реализацию логики. Оно опирается ровно на то, что ты уже прошёл: Date, getMonth(), массив месяцев, textContent, отладка через console.log.

12.1. Задание: баннер «Лучший период для старта»

Нужно сверстать блок с текстом и динамически подставляемыми датами.

HTML-структура

<p class="alert-block">
  <b>Лучшие даты <span id="date-range"></span> — для того чтобы начать</b>
</p>

Что должно происходить

  1. На странице должен выводиться текущий месяц и следующий месяц.
  2. Формат вывода: апрель и май.
  3. Если сейчас декабрь, должен выводиться текст: декабрь и январь.
  4. Никакого document.write.
  5. Вывод только через document.getElementById(...).textContent.
  6. Массив месяцев должен быть создан либо через массив, либо через split(",").
  7. Нужно добавить отладочные console.log на ключевых шагах.

Что обязательно должно быть в JS

  • создание текущей даты;
  • получение индекса текущего месяца;
  • вычисление индекса следующего месяца;
  • подстановка строки в #date-range.

Критерии готовности

  • в браузере отображается корректная пара месяцев;
  • в консоли видно все промежуточные значения;
  • код читаемый, с нормальными именами переменных;
  • нет глобальных переменных;
  • нет undefined в тексте.

12.2. Бонус-уровень: чуть интереснее, но ещё по силам

Сделай второй блок на той же странице: 

<p class="promo-block">
  <b>Окно активности: <span id="tomorrow-month"></span></b>
</p>

Логика:

  • возьми текущую дату,
  • сдвинь её на 1 день вперёд через миллисекунды,
  • покажи месяц этой новой даты.

Это уже специально — чтобы ты отдельно потренировал именно getTime() и смещение на сутки.

12.3. Ещё один бонус: мини-диапазон дат

Сделай третий блок: 

<p class="range-block">
  <b>Период: <span id="day-range"></span></b>
</p>

Логика:

  • показать сегодняшний день месяца и день месяца через 7 дней,
  • например: 19 — 26.

Здесь уже пригодится и getDate(), и смещение времени через миллисекунды.

12.4. Что ты потом должен прислать на проверку

  1. HTML-файл.
  2. JS-файл.
  3. Короткий комментарий:
    • что оказалось самым понятным,
    • где ещё остались вопросы,
    • какой вариант вычисления месяца ты в итоге выбрал.

12.5. Подсказка по порядку работы

  1. Сначала сделай только один блок.
  2. Потом выведи массив месяцев в консоль.
  3. Потом выведи текущий индекс месяца.
  4. Потом вычисли следующий индекс.
  5. Потом собери итоговую строку в переменную.
  6. И только потом подставляй в DOM.

12.6. Эталон идеи, к которой ты должен прийти сам

Ниже не готовое решение задания, а формулировка того, что ты должен уметь реализовать после методички: 

Нужно самостоятельно реализовать вывод текущего и следующего месяца
в текстовый элемент страницы, используя объект Date, массив месяцев,
вычисление индексов и textContent, без document.write и без глобальных переменных.

13. Самый короткий итог для закрепления

  • Date — встроенный объект для даты и времени.
  • new Date() — создаёт объект текущей даты.
  • getTime() — превращает дату в число миллисекунд.
  • getMonth() — даёт индекс месяца от 0 до 11.
  • split(",") — превращает строку месяцев в массив.
  • monthA[index] — достаёт месяц по индексу.
  • textContent — вставляет текст в HTML-элемент.
  • const — хорош для переменных, которые не переприсваиваются.
  • Для месяцев не нужен сдвиг на день, если задача — просто текущий и следующий месяц.
Методичка собрана под твой путь: с упором на реальные вопросы, реальные ошибки и реальные точки, где нужно было «разжевать» семантику, а не просто показать красивый код.
