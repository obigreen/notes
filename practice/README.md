# Practice Workspace

This folder is a standalone practice zone for JavaScript tasks.

## How to use

1. Open `/practice/index.html` in your browser.
2. Pick a lesson folder (`default` or `pet-practice`).
3. Work inside that lesson without running React or any build tools.

## Folder pattern

Each lesson should keep the same simple structure:

```
lesson-name/
  index.html or default.html
  css/
    styles.css
  js/
    script.js
```

`default` is the clean starter template that can be copied for new tasks.
